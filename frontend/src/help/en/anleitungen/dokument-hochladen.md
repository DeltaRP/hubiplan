1. Open [Documents](/dokumente).
2. Create a folder with **Create folder** if needed and set who sees it.
3. Open the folder and click **Upload**.
4. Choose the file and give it a title.

Anyone allowed to see the folder finds the document straight away. Deleted items stay in the bin for 30 days.
